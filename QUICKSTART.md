# Быстрый старт

Запустить Socio можно без подключения к серверу: приложение откроется с демонстрационными клиентами и услугами.

## 1. Установите зависимости

Установите Node.js 20.19+ или 22.12+, затем в папке проекта выполните:

```bash
npm ci
```

## 2. Запустите приложение

```bash
npm run dev
```

Перейдите по адресу из терминала, обычно `http://localhost:5173`. Для входа введите любой непустой логин и пароль.

## 3. Попробуйте демо

Измените количество посещений в таблице и нажмите «Экспорт в Excel». В демо используются вымышленные данные, а изменения сбрасываются после перезагрузки страницы.

## Полезные команды

```bash
npm test          # запустить тесты
npm run build     # собрать приложение
npm run preview   # открыть сборку локально
```

Инструкции по подключению своего сервера и рабочего Excel-шаблона, а также ограничения проекта — в [README](README.md).
